Democrats in Maine threaten electoral vote retaliation if Nebraska changes system

Democrats in Maine are threatening to change how the state awards Electoral College votes if Republican-led Nebraska modifies its system ahead of the 2028 presidential election. Several Democrats running to be Maine's next governor have indicated they would support adopting a winner-take-all electoral vote system if Nebraska moves away from its current allocation method.

The dispute represents the latest example of partisan election politics that could influence the outcome of the 2028 presidential race. Both Maine and Nebraska currently split their electoral votes, and any changes in how either state allocates those votes could prove decisive in a close election, particularly given the swing state dynamics that typically determine presidential contests.
